# Explore the Agent

Before the guided modules, spend a few minutes exploring on your own.

1. Open [http://localhost:5000](http://localhost:5000) (start the server with `AWS_PROFILE=ai-workshop python server.py` if it is not running).
2. Chat with the assistant. Try shopping-related requests—search products, ask about orders, request refunds or discounts.
3. See what you can do. Can you find any flaws? Are any of them exploitable?

Write down anything that surprises you. You will revisit these observations during the modules.
